# VulnPulse 🔍

**VulnPulse** is a lightweight, modular security assessment orchestrator built in Python 3. Designed for security professionals and administrators, it automates the initial phases of target reconnaissance, service enumeration, HTTP security header auditing, and dynamic risk scoring into a single unified workflow.
